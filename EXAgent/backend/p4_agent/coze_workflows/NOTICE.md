## 这次跟纯 Prompt 的核心区别

| Agent | 纯 Prompt 做法 | 工作流做法 |
|-------|--------------|-----------|
| 🔥 趋势 | LLM 说"我搜了"（其实没搜） | **必应插件真实搜索** → 代码整理数据 → LLM写报告 |
| ✍️ 脚本 | LLM 凭记忆套模板 | 代码校验参数 → **代码匹配模板结构** → LLM填充内容 |
| 🔍 审查 | LLM 自己判断 | **代码硬匹配敏感词库** → 代码平台规则枚举 → LLM只补版权判断 |
| 📊 策略 | LLM 猜时间 | 代码解析脚本内容 → **代码实时时间+平台规则** → LLM生成策略 |

## 每个工作流都有 4-5 个节点

1. **趋势**：开始 → 必应搜索(插件) → 代码(提取摘要) → LLM → 结束
2. **脚本**：开始 → 代码(参数校验) → 代码(模板匹配) → LLM → 结束
3. **审查**：开始 → 代码(敏感词硬匹配) → 代码(平台规则) → LLM → 结束
4. **策略**：开始 → 代码(解析内容) → 代码(时间+平台) → LLM → 结束
