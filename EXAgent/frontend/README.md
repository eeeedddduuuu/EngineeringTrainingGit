
# AI 数字媒体创作助手 - 前端

## 技术栈
- Streamlit
- Requests
- Pandas
- Plotly

## 安装依赖
```bash
pip install streamlit requests pandas plotly
```

## 启动前端
```bash
streamlit run streamlit_app.py --server.port 8501
```

## 访问地址
http://localhost:8501
