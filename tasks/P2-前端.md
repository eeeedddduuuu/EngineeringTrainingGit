## 接口对照（只调这些，字段格式见 docs/api_schema.md）

| 页面 | 调用的 API |
|------|-----------|
| login.py | `POST /api/auth/register` `POST /api/auth/login` |
| workspace.py | `POST /api/creation/start` `GET /api/task/{id}/status` |
| schemes.py | `GET /api/schemes?session_id=` `GET /api/scheme/{id}` `POST /api/schemes/compare` |
| history.py | `GET /api/history?page=&size=` |
| dashboard.py | `GET /api/stats/samples` |
| 导出按钮 | `GET /api/export/{scheme_id}?format=md` |

---

## 注意

- 所有请求走 `frontend/utils/api.py` 的 `api_post()` 和 `api_get()`，不要自己写 requests
- Base URL 默认 `http://localhost:8000/api`
- Token 过期时前端提示重新登录
- 所有字段名严格按 `docs/api_schema.md`，不要自己改名
