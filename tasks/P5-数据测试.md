## 样例数据要求

| 要求 | 标准 |
|------|------|
| 总数 | ≥ 30 条 |
| 平台覆盖 | douyin ≥ 10, xiaohongshu ≥ 10, bilibili ≥ 10 |
| 主题类别 | ≥ 4 类 |
| 字段完整性 | 每条 6 个字段不能有空值 |
| 来源可追溯 | source 字段写清楚从哪来的 |

## 测试案例要求

| 类型 | 数量 | 记录内容 |
|------|:----:|---------|
| 成功案例 | ≥ 5 | 输入 → 完整输出 → 耗时 → 质量评估 |
| 失败案例 | ≥ 3 | 输入 → 错误输出 → 原因 → 优化方案 → 优化后结果 |
| API 异常测试 | 全覆盖 | 401/400/404/500 场景 |

## 失败案例模板

```
编号: F-001
输入: 主题="AI大模型技术解析" 受众="普通用户" 平台="douyin" 时长="30s"
输出: 技术术语过多，开头无吸引力
原因: Prompt 未指定面向零基础用户的语言风格
优化: Prompt 增加「用小学生能听懂的语言解释」
结果: 生成内容通俗化，开头改为生活场景切入
```
