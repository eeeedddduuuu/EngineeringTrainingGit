# P3 后端开发 · 任务清单

**技术栈：** FastAPI + SQLAlchemy + SQLite + JWT

---

## 文件结构（已建好基础框架）

```
backend/
├── app/
│   ├── main.py            ← FastAPI 入口 + CORS（已实现）
│   ├── config.py          ← 配置（已实现）
│   ├── database.py        ← SQLAlchemy 连接（已实现）
│   ├── models/
│   │   ├── user.py        ← User 模型（已实现）
│   │   └── business.py    ← Session/Scheme/AgentLog/KnowledgeItem（已定义）
│   ├── schemas/
│   │   ├── auth.py        ← 注册/登录请求体（已实现）
│   │   └── creation.py    ← 创作相关请求体（已实现）
│   ├── routers/
│   │   ├── auth.py        ← 注册/登录/me（已实现框架）
│   │   └── creation.py    ← 创作/任务状态/方案（待实现）
│   └── utils/
│       └── security.py    ← JWT + 密码哈希（已实现）
├── prompts/               ← Agent Prompt 模板（P4 维护，你只读）
└── requirements.txt       ← 依赖（已写好）
```

---

## Day 1 必须完成

- [ ] `pip install -r requirements.txt`
- [ ] `uvicorn app.main:app --reload` 能启动，浏览器打开 `http://localhost:8000/docs` 能看到 Swagger
- [ ] 数据库首次初始化：运行后自动建表（在 `main.py` 加 startup 事件 `Base.metadata.create_all`）
- [ ] `POST /api/auth/register` 能注册用户，重复用户名返回 400
- [ ] `POST /api/auth/login` 能登录返回 JWT，密码错误返回 401
- [ ] `GET /api/auth/me` 能从 Token 解析用户信息
- [ ] 用 Swagger UI 自测全部通过
- [ ] **提交 Git：** `feat(backend): 完成用户认证 API 和数据库建表`

## Day 2 必须完成

- [ ] 实现 `POST /api/creation/start`：接收创作请求 → 在 sessions 表创建记录 → 返回 task_id
- [ ] 实现 `GET /api/task/{task_id}/status`：查 sessions 表返回状态（Day 2 先返假数据，P4 开发完对接）
- [ ] 实现 `GET /api/schemes?session_id=`：查 schemes 表
- [ ] 实现 `GET /api/scheme/{id}`：查单条 scheme
- [ ] 实现 `POST /api/schemes/compare`：查 2-3 个 scheme 返回对比
- [ ] 实现 `GET /api/history?page=&size=`：分页查当前用户的 sessions
- [ ] 实现 `GET /api/export/{scheme_id}?format=md`：拼 Markdown 文本返回文件
- [ ] 所有接口加 `Depends(get_current_user)` 做 Token 校验
- [ ] **提交 Git：** `feat(backend): 完成创作、方案、历史、导出 API`

## Day 3 必须完成

- [ ] 与 P4 对接：P4 调创作 API 后，后端异步调用 P4 的 Agent 函数，更新 task 状态
- [ ] 实现统一的异常处理中间件（所有未捕获异常返回 500）
- [ ] 任务超时处理（超过 120 秒标记 failed）
- [ ] 全流程联调（与 P2、P4）
- [ ] **提交 Git：** `feat(backend): Agent 对接、异常处理和超时控制`

## Day 4 必须完成

- [ ] Bug 修复
- [ ] 日志补全
- [ ] 配合 P2 部署联调
- [ ] Swagger 截图（给 PM 用于报告）

## 接口清单（严格按 docs/api_schema.md 的请求/响应格式）

| 方法 | 路径 | 说明 | 优先级 |
|------|------|------|--------|
| POST | `/api/auth/register` | 注册 | Day 1 |

| GET | `/api/auth/me` | 用户信息 | Day 1 |
| POST | `/api/creation/start` | 提交创作 | Day 2 |
| GET | `/api/task/{task_id}/status` | 任务状态 | Day 2 |
| GET | `/api/schemes?session_id=` | 方案列表 | Day 2 |
| GET | `/api/scheme/{id}` | 方案详情 | Day 2 |
| POST | `/api/schemes/compare` | A/B 对比 | Day 2 |

| GET | `/api/export/{scheme_id}?format=md` | 导出 | Day 2 |

## 注意

- 所有字段名、类型、枚举值与 `docs/api_schema.md` 完全一致，不允许自创
- SQLite 路径写 `sqlite:///./app.db`，首次启动自动建表
- JWT Token 过期时间 24 小时
- CORS 已配 `allow_origins=["*"]`，不要改
- P4 对接前先用假数据保证 P2 能联调
