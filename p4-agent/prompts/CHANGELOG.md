# Prompt 迭代变更记录

## v1 → 后续迭代指南

### 迭代方向

1. **脚本创作 Agent**
   - 当前 V1: 通用短视频脚本（基于 Day10 Coze V1.2 + Day09 writer V3）
   - V2 计划: 增加"多平台差异化"参数，根据抖音/小红书/B站自动调整开头风格
   - V3 计划: 增加"对标账号风格模仿"功能

2. **热点分析 Agent**
   - 当前 V1: 基于 web_search 的通用热点发现
   - V2 计划: 增加"垂类热点"概念（如只分析游戏/美妆/科技等特定领域）
   - V3 计划: 增加"热点生命周期预测"

3. **合规审查 Agent**
   - 当前 V1: 基础敏感词+隐私检查（基于 Day11 规则）
   - V2 计划: 增加"广告法合规"检查
   - V3 计划: 增加"平台差异化审核规则"

4. **发布策略 Agent**
   - 当前 V1: 通用发布时间+标签建议
   - V2 计划: 增加"竞品发布时间避让"分析
   - V3 计划: 增加"A/B测试方案生成"

### 已知问题

- 来源：Day09 温度实验结论 — deepseek-v4-pro 在 temperature >= 0.7 时可能输出空内容
- 建议：脚本创作/合规审查用 temperature 0.3-0.5，热点分析/发布策略用 0.6-0.7
