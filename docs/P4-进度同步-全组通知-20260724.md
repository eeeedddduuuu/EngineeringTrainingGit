## 一、目前完成了什么

| 模块 | 完成内容 | 说明 |
|------|---------|------|
| **Provider 层** | Mock / Coze / Dify / DeepSeek 四后端 | 默认 Mock（离线可跑），答辩前切真实 API |
| **工具集** | 5 个工具 | 网页搜索、知识库检索、敏感词过滤、模板匹配、时间 |
| **4 个 Agent** | trend → script → review → strategy | 热点分析 → 脚本创作 → 合规审查 → 发布策略 |
| **Prompt 模板** | 4 个 YAML | 独立存放 `prompts/`，含角色设定+输出格式+工具指引 |
| **工作流编排** | YAML 配置 | 串并联流水线，各 Agent 间数据自动传递 |
| **评分算法** | 5 维度加权 | 钩子吸引力 25%、平台匹配 20%、受众匹配 20%、原创性 15%、可执行性 20% |
| **Parser 层** | Markdown → JSON | Agent 输出自动解析为结构化数据，匹配 P3 数据库字段 |
| **对接入口** | `create_content()` | 一行调用，返回可直接入库的 agent_logs + schemes |

> Mock 模式下 4 Agent 全通，流水线闭环 OK，端到端验证通过。

## 二、P3 对接状态 ✅

已根据 P3 的通知完成三项对齐：

1. **Agent 名称统一**：第四个 Agent 改为 `strategy`，与 P3 `agent_logs.agent_name` 一致
2. **Parser 层**：脚本输出的 Markdown 自动解析为 Scheme 表结构（version/title/hook/scenes/hashtags/cover_text）
3. **对接入口**：`create_content()` 直接接收 P3 的 CreationRequest 字段，返回 `agent_logs` + `schemes`

**P3 对接时只需要：**
```python
from pipeline_adapter import create_content
result = create_content(topic="...", target_audience="...", platform="douyin", duration="60s", style="...", provider="mock")
# result["agent_logs"] → 写入 agent_logs 表
# result["schemes"]   → 写入 schemes 表
```
