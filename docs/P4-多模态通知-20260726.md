## 使用方式

### Python 代码

```python
from p4_agent.multimodal import image_to_script, generate_tts
from p4_agent.pipeline_adapter import create_content

# 方式1：图片→脚本（走完整 Coze 流水线）
result = create_content(
    topic="AI工具测评",
    target_audience="职场人",
    platform="douyin",
    duration="60s",
    style="干货",
    provider="coze",
    image_url="uploads/your_image.jpg",  # P3 上传的文件
)

# 方式2：单独使用多模态
analysis = image_to_script("uploads/poster.jpg", "小红书", "种草")
tts = generate_tts("欢迎收看本期AI工具测评", speaker="zh_female_qingxin")
```

### API 调用（P2 前端）

P3 已经实现了：

| 端点 | 用途 |
|------|------|
| `POST /api/creation/upload` | 上传图片/视频/音频 |
| `POST /api/creation/start` | 创作请求加 `image_url` 字段 |
