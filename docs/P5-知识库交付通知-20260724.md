### 1. 知识库检索 API（P4 可直接对接）

**接口：** `GET /api/knowledge/search?q={关键词}&top_k={数量}`

**示例请求：**
```
GET http://localhost:8000/api/knowledge/search?q=短视频脚本创作&top_k=5
```

**示例响应：**
```json
{
  "query": "短视频脚本创作",
  "results": [
    {
      "id": 12,
      "title": "短视频脚本创作：先"抄"竞品找对标，减少试错成本",
      "content_snippet": "标题: 短视频脚本创作...\n标签: 短视频创作\n平台: 抖音...",
      "platform": "抖音",
      "tags": ["短视频创作"],
      "source": "抖音 @创作学院",
      "published_at": "2024-06-15",
      "similarity": 0.714
    }
  ]
}
```

**技术细节：**
- Embedding 模型：`BAAI/bge-small-zh-v1.5`（中文语义检索）
- 向量数据库：Chroma（本地持久化存储）
- 数据量：50 条样例数据
- 检索质量：语义匹配准确，同类查询 Top-1 相似度 >0.7

## 🔗 P4 对接指引

P4 的 `knowledge_search` 工具可从 Mock 切换到真实调用：

```python
# 在 P4 Agent 代码中，替换 Mock 调用为真实 HTTP 请求：
import httpx

def search_knowledge(query: str, top_k: int = 5) -> dict:
    resp = httpx.get(
        "http://localhost:8000/api/knowledge/search",
        params={"q": query, "top_k": top_k},
        timeout=30.0,
    )
    return resp.json()
```
