### 4 Agent 流水线

```
用户输入(主题+受众+平台+时长+风格)
    │
    ├─→ ① Trend  热点分析  → 趋势报告 + 切入角度
    ├─→ ② Script 脚本创作  → A/B/C 3候选方案(含分镜表/标签/封面)
    ├─→ ③ Review 合规审查  → pass / review / block
    └─→ ④ Strategy 发布策略 → 最佳时间 + 运营建议
                │
    └─→ 5维度评分 → 加权排名 → 推荐最佳方案
```

### 评分体系

| 维度 | 权重 | 评估内容 |
|------|:--:|------|
| 开头钩子吸引力 | 25% | 前3秒能否抓住注意力 |
| 结构与平台匹配 | 20% | 时长/节奏/格式规范 |
| 目标受众匹配 | 20% | 语言风格契合度 |
| 内容原创性 | 15% | 与知识库差异化 |
| 可执行性 | 20% | 拍摄难度/成本 |

## 三、组员接入指南

### 前置条件

- Python 3.9+
- Git 已配置（用户名 + 邮箱 + SSH）
- 项目已 clone 到本地，在 `develop` 分支

### Step 1：拉取最新代码

```bash
cd 项目目录
git checkout develop
git pull origin develop
```

### Step 2：安装后端依赖

```bash
cd backend
pip install -r requirements.txt
```

### Step 3：配置 DeepSeek API Key（每人自己申请）

**为什么用 DeepSeek：** 国内直连、价格极低、API 兼容 OpenAI 格式、不需要提前搭建 Bot 或工作流。

1. 打开 https://platform.deepseek.com
2. 注册/登录 → API Keys → 创建新 Key → 复制
3. 在 `backend/p4_agent/config/providers.json` 中填入：

```json
{
  "deepseek": {
    "api_key": "sk-你的key填这里",
    "base_url": "https://api.deepseek.com/v1",
    "model": "deepseek-chat"
  }
}
```

> ⚠️ **不要提交 API Key 到 Git！** `providers.json` 已在 `.gitignore` 或提交前务必还原为占位符。

### Step 4：初始化数据库

```bash
cd backend
python init_db.py
```

### Step 5：启动后端

```bash
# Windows PowerShell
$env:HF_ENDPOINT = "https://hf-mirror.com"
uvicorn app.main:app --reload --port 8000
```

浏览器打开 http://localhost:8000/docs 确认 15 个 API 全部注册。

### Step 6：启动前端

```bash
cd frontend
pip install streamlit requests pandas plotly
streamlit run app.py
```

浏览器打开 http://localhost:8501

### Step 7：验证 Agent

**Mock 模式（无需 API Key）：**
```bash
cd backend/p4_agent
python main.py --mode all
```
应该看到 4 个 Agent 全部 `[OK]`，3 个方案评分排名正常。

**DeepSeek 真实模式（需先配好 Key）：**
```bash
python main.py --mode all --provider deepseek
```

## 四、切换 Provider 说明

三个 Provider 共享同一套 Agent + Prompt + 评分逻辑，**只改一个参数**：

| 切换方式 | 代码 | 前提 |
|---------|------|------|
| 默认 Mock | `provider="mock"` | 无 |
| 切 DeepSeek | `provider="deepseek"` | 配 `api_key` |
| 切 Coze | `provider="coze"` | Coze 平台建好 Bot |
| 切 Dify | `provider="dify"` | Dify 实例 + 创建应用 |

P3 `creation.py` 中修改：
```python
result = create_content(
    topic=...,
    target_audience=...,
    platform=...,
    duration=...,
    style=...,
    provider="deepseek",   # ← 这里改
)
```
