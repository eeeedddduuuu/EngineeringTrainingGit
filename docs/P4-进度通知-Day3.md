## 多模态需求确认

题目3 要求 #16：

> 支持图片、视频或音频素材输入，生成多模态创作方案

### 我的方案

在 Coze 脚本创作 Agent 中接入多模态能力：

1. **图片输入** → 用户上传素材图，后端提取 → Coze 分析画面内容，生成匹配的脚本和封面文案
2. **视频输入**（选做）→ FFmpeg 抽关键帧 → 分析帧内容 → 生成创作建议
3. **音频输入**（选做）→ whisper 转文字 → 提取关键词 → 生成脚本

### 需要协作

| 依赖 | 负责 | 说明 |
|------|:--:|------|
| 图片上传 API | P3 | `/api/creation/start` 支持 `image_url` 参数 |
| 视频抽帧 | P3/P5 | FFmpeg + OpenCV 关键帧提取 |

### 实现优先级

先做图片（Coze 本身支持图片识别），视频和音频有余力再搞。
