## 二、数据流

```
采集 → 清洗 → 分块 → Embedding → 存入 Chroma → 提供检索 API
```

| 步骤 | 工具 | 说明 |
|------|------|------|
| **采集** | 人工整理 | 从抖音/小红书/B站公开内容整理 50 条素材 |
| **清洗** | pandas | 去重、格式标准化、元数据提取 |
| **分块** | 字段拼接 | 标题+标签+平台+摘要 → 检索文本 |
| **Embedding** | `bge-small-zh-v1.5` | 文本 → 512维向量（本地运行） |
| **向量库** | Chroma | 余弦相似度检索，持久化存储 |
| **检索 API** | FastAPI | `GET /api/knowledge/search?q=&top_k=` |

## 四、技术选型理由

| 技术 | 为什么选它 |
|------|------|
| **Chroma** | 轻量、Python 原生、零运维部署，课程项目首选 |
| **bge-small-zh-v1.5** | 中文语义检索 SOTA 模型，本地运行零成本，不需要 API Key |
| **sentence-transformers** | 成熟的 Embedding 框架，API 简洁 |
| **pandas** | 数据处理标配，读写 xlsx/csv，统计分析方便 |
| **pytest + httpx** | 自动化测试，19 条覆盖全 API |

## 七、与 Agent 的协作

```
P4 Agent (脚本创作)
    │
    ├─→ tools/knowledge_search(query)
    │       │
    │       ▼
    │   GET /api/knowledge/search?q=query&top_k=5
    │       │
    │       ▼
    │   Chroma 语义检索 → 返回 Top-5 相关案例
    │       │
    │       ▼
    │   Agent 参考检索结果 → 生成脚本/分镜/文案
    │
    └─→ 将检索来源作为引用展示给用户
```
