# 需求分析文档

## 1. 产品定位

面向短视频创作者、游戏策划、社交媒体品牌运营的 AI 创作助手系统。用户只需输入创作需求（主题、目标受众、发布平台、时长、风格），系统通过多 Agent 协作自动生成多版本脚本、分镜表、封面文案和发布策略。

**核心价值：** 将单个创作者 2-3 小时的脚本构思 + 文案撰写工作压缩到 2 分钟。

## 2. 目标用户画像

### 用户A：短视频博主（核心用户）
- **年龄：** 22-30 岁
- **场景：** 日均创作 1-2 条短视频，需要持续产出内容
- **痛点：** 脚本构思耗时，不知道什么样的开头能留住观众，容易灵感枯竭
- **常用平台：** 抖音、小红书
- **期望：** 输入主题就能拿到 3 个不同风格的可直接拍摄脚本，附带 A/B 测试建议

### 用户B：游戏策划师
- **年龄：** 25-35 岁
- **场景：** 需要为游戏角色 PV、版本宣传片写脚本和分镜
- **痛点：** 需要规范的分镜表和世界观设定，对创意和逻辑一致性要求高
- **常用平台：** B站、游戏社区
- **期望：** 输出包含分镜表、角色对白、世界观设定的完整创作方案

### 用户C：品牌运营专员
- **年龄：** 22-32 岁
- **场景：** 同时管理品牌在抖音、小红书、公众号等多个社交媒体账号
- **痛点：** 同一主题需要针对不同平台写不同风格的内容，重复劳动多
- **常用平台：** 抖音 + 小红书 + 公众号
- **期望：** 输入一个主题 → 自动生成适配不同平台的多个版本

## 3. 核心业务流程

```
用户登录 → 进入创作工作台
              │
              ▼
     输入创作需求（主题/受众/平台/时长/风格）
              │
              ▼
     POST /api/creation/start → 返回 task_id
              │
              ▼
     ┌──── 异步处理（Agent 流水线）────┐
     │                                │
     │  热点分析 Agent                 │
     │  ├─ 搜索工具：抓取相关热点      │
     │  └─ 输出：热点话题摘要          │
     │              │                 │
     │              ▼                 │
     │  脚本创作 Agent                 │
     │  ├─ 知识库检索：同类爆款脚本    │
     │  ├─ 模板匹配：平台+时长结构模板 │
     │  └─ 输出：3 个候选脚本+分镜表  │
     │              │                 │
     │              ▼                 │
     │  合规审查 Agent                 │
     │  ├─ 敏感词过滤                 │
     │  ├─ 版权风险检查               │
     │  └─ 输出：审查结论+修改建议    │
     │              │                 │
     │              ▼                 │
     │  发布策略 Agent                 │
     │  ├─ 平台模板适配               │
     │  ├─ 多维度评分排序             │
     │  └─ 输出：推荐方案+A/B对比     │
     │                                │
     └────────────────────────────────┘
              │
              ▼
     前端轮询 GET /api/task/{id}/status
              │
              ▼
     展示 3 个候选方案 + 推荐理由 + A/B 对比
              │
              ▼
     用户选择 → 导出 Markdown / 重新生成 / 保存
```

## 5. 功能范围

### 基本功能（必须实现）
1. 用户注册、登录、退出和个人偏好设置
2. 创作工作台：输入主题、目标受众、发布平台、时长、风格
3. 多 Agent 协作：热点分析 → 脚本创作 → 合规审查 → 发布策略
4. 生成不少于 3 个候选方案，含推荐理由和 A/B 对比
5. 历史会话记录查看和方案版本对比
6. 知识库检索并展示引用来源
7. 方案导出为 Markdown 格式
8. 样例数据统计看板（主题分布、平台分布、时间趋势）

### 进阶功能（选做加分）
1. 接收图片/视频/音频素材输入，生成多模态创作方案
2. 成员在线审核、版本回退和创作任务看板
3. 自动生成短视频样片（TTS + 图像生成 + FFmpeg 拼接）
4. Prompt 实验台：不同模型/参数批量测试和可视化对比
5. 跨平台内容发布排期日历

## 6. 技术选型说明

| 技术 | 用途 | 选型理由 |
|------|------|---------|
| Streamlit | 前端 | Python 开发，学习成本低，快速出原型 |
| FastAPI | 后端框架 | 高性能异步、自动 Swagger 文档、Pydantic 校验 |
| SQLite | 数据库 | 零配置、便携，课程项目足够（后期可换 MySQL） |
| LangChain | Agent 编排 | 灵活的链式调用和工具集成，答辩展示代码深度 |
| DeepSeek | LLM | 性价比极高（约 GPT-4 的 1/50），中文能力强 |
| Chroma | 向量数据库 | 轻量、Python 原生、零部署 |
| BGE | Embedding | 中文语义检索效果优秀，本地运行零成本 |

## 7. 数据来源说明

- 样例数据从抖音、小红书、B站公开页面人工整理
- 知识库内容基于公开的创作教程、平台规范和优秀案例
- 所有数据仅用于课程项目展示，不涉及商业用途
- 数据标注来源、平台和采集时间，确保可追溯
