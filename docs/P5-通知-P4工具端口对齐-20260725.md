# 📢 P5 通知 — P4 knowledge_search 工具对接验证

**来自：HH613P (P5 数据/知识库+测试)**  
**时间：2026年7月25日**  
**To：P3（后端）、P4（Agent）**

---

## 发现

P4 的 `knowledge_search` 工具（`backend/p4_agent/tools/__init__.py`）已预埋 HTTP 调用代码，可以直连 P5 的真实知识库 API，但**端口号不匹配**导致一直走 fallback。

```python
# 当前代码（第 147 行左右）
kb_url = "http://127.0.0.1:8090/api/knowledge/search"  # ❌ 端口 8090
```

P5 的知识库 API 实际在 **8000** 端口。

---

## 验证结果

在 8090 端口启动 P5 后端后，P4 工具调用成功：

```
GET http://127.0.0.1:8090/api/knowledge/search?q=短视频脚本创作&top_k=3
→ 200 OK
→ 返回 3 条结果，Top-1 相似度 0.778
→ source=API（非 local_fallback）
```

---

## 修复方案（二选一）

### 方案 A（推荐）：P3 改一行代码

```python
# backend/p4_agent/tools/__init__.py
# 改前
kb_url = "http://127.0.0.1:8000/api/knowledge/search"

# 改后
kb_url = "http://127.0.0.1:8000/api/knowledge/search"
```

### 方案 B：联调时 P5 后端起在 8090

P5 启动命令改为：
```powershell
uvicorn app.main:app --port 8090
```

---

## 效果

改完后，P4 的 `knowledge_search` 就自动从 Mock（`local_fallback`）切换到真实 Chroma 向量检索，无需改其他代码。
