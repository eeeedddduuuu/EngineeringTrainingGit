```
│   ├── script_agent_v1.yaml       # 脚本创作 Agent
│   ├── review_agent_v1.yaml       # 合规审查 Agent
│   └── strategy_agent_v1.yaml     # 发布策略 Agent
├── config/providers.json           # Provider 配置文件
└── outputs/                        # 运行结果输出目录
```

### 4 个 Agent 流水线

```
用户输入(主题+受众+平台+时长+风格)
    │
    ├─→ Trend 热点分析  ──→ 趋势报告 + 切入角度建议
    ├─→ Script 脚本创作 ──→ 3个候选方案 (A/B/C)，含分镜表/标签/封面文案
    ├─→ Review 合规审查 ──→ 敏感词检查 + 风险评级 (pass/review/block)
    └─→ Strategy 发布策略 → 最佳发布时间 + 运营建议
                │
    └─→ 评分排名 → 5维度加权 → 推荐最佳方案
```

### 评分体系（5 维度加权）

| 维度 | 权重 | 说明 |
|------|:--:|------|
| 开头钩子吸引力 | 25% | 前 3 秒抓住注意力 |
| 结构与平台匹配 | 20% | 时长/节奏/格式规范 |
| 目标受众匹配 | 20% | 内容风格契合度 |
| 内容原创性 | 15% | 与知识库差异化程度 |
| 可执行性 | 20% | 拍摄难度/成本评估 |
