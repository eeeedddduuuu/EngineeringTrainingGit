## 一、命名规范（全组强制统一）

### 命名格式

```
角色编号_模块_具体内容.png
```

### 示例

```
P2_工作台_创作需求输入.png
P3_Swagger_API接口总览.png
P4_Agent_工作流架构图.png
P5_看板_样例主题分布图.png
PM_架构_系统架构图.png
```

### 规则

| 规则 | 说明 |
|------|------|
| 分隔符 | 下划线 `_` |
| 语言 | 中文（方便报告插入时识别） |
| 格式 | PNG（优先）或 JPG，分辨率 ≥ 1920×1080 |
| 角色编号 | P2 / P3 / P4 / P5 / PM |
| 模块 | 用页面名或功能名（见下方各角色清单中的"文件名"列） |
| 禁止 | 不要用 `截屏2026-07-25 14.30.25.png` 这类默认名 |

### 截图质量要求

| 项目 | 标准 |
|------|------|
| 分辨率 | ≥ 1920×1080（全屏截图） |
| 内容 | 不要截到桌面、任务栏、浏览器标签页（按需裁剪） |
| 标注 | 关键区域可用红框/箭头标注（可选） |
| 完整性 | 功能页面需包含完整表单/结果/状态信息 |
