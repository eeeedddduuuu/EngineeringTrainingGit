# 豆包识图工具 — 使用指南

## 这是什么

一个基于**火山引擎豆包视觉模型**的 Python 识图脚本。把图片拖进去，AI 帮你描述、分析、对比。

支持：单图详细分析、多图对比、几十张图并发批量处理。

## 能干什么

- **单图识别** — 描述角色、色彩、构图、风格、细节
- **多图对比** — 比较几张图的差异（画风、角色、色彩等）
- **批量处理** — 几十上百张图并发跑，自动收集结果
- **自定义提问** — 想让它看什么就写什么问题

## 5 分钟上手

### 第一步：装依赖

```bash
pip install requests
```

### 第二步：搞个 API Key

1. 打开 https://console.volcengine.com/ark
2. 注册/登录火山引擎
3. 左侧「推理接入点」→ 创建接入点 → 选 doubao-seed-2-1-pro
4. 「API Key 管理」→ 创建 Key → 复制

### 第三步：设置环境变量

**Windows (CMD)：**
```cmd
set ARK_API_KEY=你的key
```

**Windows (PowerShell)：**
```powershell
$env:ARK_API_KEY="你的key"
```

**Linux/Mac：**
```bash
export ARK_API_KEY=你的key
```

### 第四步：开跑

```bash
# 最简单的用法：描述一张图
python vision_doubao.py cat.jpg

# 带问题
python vision_doubao.py cat.jpg -q "这只猫是什么品种，毛色有什么特点"

# 对比两张图
python vision_doubao.py a.jpg b.jpg -c

# 用最强的模型
python vision_doubao.py artwork.png -m pro21 -q "分析这张插画的绘画技法、色彩构成和构图"
```

## 常用命令

| 命令 | 作用 |
|------|------|
| `python vision_doubao.py img.jpg` | 自动描述一张图 |
| `python vision_doubao.py img.jpg -q "问题"` | 带着问题看图 |
| `python vision_doubao.py a.jpg b.jpg -c` | 对比两张图 |
| `python vision_doubao.py img.jpg -m pro21` | 指定模型（默认自动选） |
| `python vision_doubao.py --list-models` | 看有哪些模型 |
| `python vision_doubao.py --budget` | 看今天花了多少钱 |

## 模型怎么选

| 别名 | 能力 | 价格 | 适合 |
|------|------|------|------|
| `mini` | 基础 | ¥0.15/百万token | 简单判断：是什么、有几个 |
| `lite` | 中等 | ¥0.30/百万token | 日常识别、描述 |
| `turbo21` | 较强 | ¥0.80/百万token | 批量标图、快速分类 |
| `pro21` | 最强 | ¥2.00/百万token | 画风分析、详细评审 |

不写 `-m` 的话脚本会自动选：简单问题用 mini，复杂问题用 lite。

> 一张图大概消耗几千 token，即便是 pro21 模型，一张图也就几分钱。

## Python 代码调用

### 单张图识别

```python
from vision_doubao import call_vision

result = call_vision(["image.jpg"], "描述这张图片的风格和特点")

if result["success"]:
    print(result["content"])     # AI 返回的文字
    print(result["usage"])       # token 用量
    print(result["cost"])        # 花了多少钱
else:
    print(f"失败: {result['error']}")
```

### 批量处理（并发池）

```python
from vision_doubao import VisionPool

# 创建池子：最多 10 个同时跑
pool = VisionPool(max_workers=10, verbose=True)

# 提交一堆图片
images = ["img1.jpg", "img2.jpg", "img3.jpg", ...]
for img in images:
    pool.submit([img], "描述这张图", retries=3)

# 等全部跑完
stats = pool.wait_all()
print(f"完成 {stats['completed']}，失败 {stats['failed']}")

# 拿结果
for task_id, result in stats["results"].items():
    if result["success"]:
        print(f"{task_id}: {result['content'][:100]}...")

pool.shutdown()
```

### 多图批量对比

```python
pool = VisionPool(max_workers=5)

# 一次性发 3 张图给豆包做对比
pool.submit_batch(
    ["version_a.jpg", "version_b.jpg", "version_c.jpg"],
    "对比这三张的区别：画风、配色、角色设计",
    task_id="compare",
    max_images=4
)

result = pool.submit_and_wait(["single.jpg"], "描述这张图")
pool.shutdown()
```

## VisionPool 方法速查

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `submit([paths], question, task_id, retries)` | 提交任务 | task_id |
| `submit_batch([paths], question, task_id, max_images, retries)` | 多图批量 | task_id 列表 |
| `submit_and_wait([paths], question)` | 提交并等结果 | result dict |
| `get_result(task_id)` | 查结果 | result dict |
| `wait_all()` | 等所有完成 | 统计 + 全部结果 |
| `stats()` | 看进度 | submitted/completed/failed/pending |
| `shutdown()` | 关闭池子 | — |

## 常见问题

**Q: 报错 "未设置 ARK_API_KEY"**
A: 你没设环境变量。跑一下 `set ARK_API_KEY=你的key`。

**Q: 图片太大报错？**
A: 图片建议 2MB 以下。太大的先压缩一下。

**Q: 多图一起发多少张合适？**
A: 详细分析 2-4 张/次，快速归类可以 10 张/次。太多张质量会稀释。

**Q: 超时报错？**
A: 网络波动，重试就好。`pool.submit(..., retries=3)` 会自动重试。

**Q: 支持的图片格式？**
A: PNG、JPG、JPEG、WEBP、GIF、BMP。

**Q: 烧钱快不快？**
A: 一张图差不多 3000-8000 token。用 lite 模型的话 100 张图也就几毛钱。
